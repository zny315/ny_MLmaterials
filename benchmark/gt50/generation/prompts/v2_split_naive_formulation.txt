
Extract sample-level formulation data for EVA/PE/POE flame-retardant materials.
This task is formulation/parts only. Do not extract performance values.
Use "#" for missing values. Return valid JSON only.

Use these field meanings at minimum:
- samples: one row per material sample/formulation.
- entities: material components in that sample formulation.
- parts: subcomponents inside a modified, coated, grafted, encapsulated, hybrid, or composite entity.
- sample_name: exact sample code or material name used in the paper.
- matrix: polymer matrix names.
- matrix_system: EVA, PE, EVA/PE, EVA/POE, EVA/PE/POE, other, or #.
- formulation_basis: wt_total, wt_polymer_blend, phr_resin, parts_by_weight, unknown, or #.
- entity_name: component name.
- entity_role: matrix_polymer, main_flame_retardant, synergistic_flame_retardant, functional_filler, compatibilizer, crosslinking_agent, co_crosslinking_agent, processing_aid, other_additive, or #.
- entity_type: pristine, surface_treated, grafted_additive, core_shell, microencapsulated, coated, intercalated, doped, in_situ_grown, hybrid_complex, matrix_grafted, blend_package, unknown, or #.
- entity_loading fields: component loading value, original text, unit, basis, and normalized wt% or phr if directly available or clearly convertible.
- entity_material_type: 1 for polymer-based component, 0 for non-polymer component, or # if unclear.
- part_name: subcomponent name.
- part_role: base/core/shell/coating_layer/grafted_moiety/grafted_backbone/coupling_agent/surface_ligand/modifier/dopant/metal_center/organic_ligand/synergistic_part/other_part, or #.
- relation_to_entity: part_of, core_of, shell_of, grafted_to, grafted_from, coated_on, encapsulates, doped_in, intercalated_in, complexed_with, surface_treated_by, modified_by, or #.
- modification_method: none, surface_treatment, coating, grafting, encapsulation, intercalation, doping, in_situ_growth, complexation, blending, or #.
- part_ratio/loading fields: internal ratio or subcomponent loading when reported.
